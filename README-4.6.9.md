# Everyone 4.6.9

改进任务取消：连接断开在独立线程清理，取消标志立即生效；重复取消只清理一次；取消之后才返回的连接也会释放。任务的自定义状态检查移到任务锁外，避免与会话锁互相等待。数据库进入最终提交后的保护规则保持不变。

15 项新取消/锁竞争检查及 8 项既有提交边界检查通过；连同 179 项语音控制检查和 6 项精确恢复检查，共 208 项主机检查。真实手机与真实服务延迟尚未实测。

4.6.8 的完整 APK 和签名恢复资料已经发布到 Zizai 私有仓库的 `everyone-v4.6.8`。新的精确恢复流程验证整个 APK 的 SHA-256，保留原签名与压缩结构；模型、音频和本地库从已保存基线恢复。4.6.9 的完整 APK、恢复包和签名资料已发布到私有仓库的 `everyone-v4.6.9`。

当前源码是 4.6.2 完整基线和恢复出的录音/朗读/任务取消增量，中间版本完整 Java 源码仍未恢复。现有功能通过经过校验的编译快照与精确恢复包保留，普通 `build.sh` 不能视为当前完整安装包的构建入口。

4.6.9 只替换了 `CloudClient.Job` 及其连接清理辅助类。其余 1000 个类、347 个模型/内容/本地库/资源项与 4.6.8 一致。原签名覆盖安装，系统版本为 4.6.9，versionCode 55；旧诊断标题仍可能使用 4.6.3 标签。
