# Everyone 4.7.1

修复流式句点的提前分段：回调末尾的 ASCII 句点先等待下一字符或生成结束，避免 `example.` 后续变成 `example.com` 时已被拆开朗读，也避免逐字生成的 `Wait...` 丢失省略号。混合语言段落中的域名句点同样受保护。确认空白、收尾引号或明确分句边界后仍可提前朗读；生成完成时立即刷新最后一句。短问候、问句、中文标点及长句完整词分段继续保留。

新增 16 项检查覆盖域名、路径、省略号、称谓、中文夹网址、逐字累积回调和最终重复回调。71 项流式朗读检查，连同录音、取消、提交边界及精确恢复检查，共 236 项主机检查通过。句点位于最后一个未完成 token 时，会多等待下一次回调或结束通知；尚未进行手机声学或端到端延迟实测。

本轮仅替换 `StreamingSpeechChunks`。其余 1001 个编译类、347 个模型/内容/资源/本地库项与 4.7.0 一致。版本为 4.7.1，versionCode 57，沿用原签名，可直接覆盖安装，保留学习及聊天数据。部分旧诊断标题仍可能使用 4.6.3 标签。
