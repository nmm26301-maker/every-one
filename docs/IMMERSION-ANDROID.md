# Everyone · 原生影视精听（Undertone 风格学习体验）

本分支新增 **Android 原生影视精听**，入口位于 Everyone 5.0 首页的“影视精听 · 双语字幕 / 逐句复读”。它不依赖浏览器扩展，和 Undertone 弦外没有商业、技术或授权关联。

## 已实现的能力（源码）

- 安卓系统文件选择器导入本地视频（播放器使用系统 `VideoView`，格式依手机解码器而定）。
- 分别加载日文或英文 **SRT/WebVTT** 原文字幕，以及中文字幕；按时间轴而非相同序号配对。
- 视频时间轴自动定位台词，点字幕列表跳转、上一句、下一句、重播。
- 可选句末暂停或单句循环（短句及播放器 seek 精度因手机而异）。
- 选择台词后保存到本地收藏（原文/译文），导出 Anki 可导入的 TSV。
- 少量**规则式**日语口语缩略提示：`ちゃった`、`じゃん`、`っす`、`ちょっと`、`考えておきます`。
- 播放与字幕无需网络，未集成付费 API，不上传用户视频。


## 粤语 · Jyutping + 影视台词学习（2026-10-21）

在原来的英语、日语影视精听功能之外，同一个页面加入 **粤语**：

- 首页语言切换：粤语 / 日语 / 英语，保留上一次选项；默认粤语。
- 粤语电影/电视剧原声视频可以配合用户导入的粤语 SRT / WebVTT 和中文字幕做逐句学习。
- 内置 10 句繁体粤语入门练习，显示香港语言学学会粤拼（Jyutping，六调数字 1–6）、普通话意思与基础发音提示。
- 点击粤语字幕中的「显示口语说明」，可从内置常见词条列表逐项查看词义和粤拼。覆盖唔、冇、喺、係、咗、緊、啲、嘅、咩等常见影视词。
- 「跟读识别 · 对照文本」会调用手机现有的系统语音识别，粤语使用请求语言 \`zh-HK\`，日语 \`ja-JP\`，英语 \`en-US\`。可对比识别到的文字和字幕原文，方便自主回听原声；系统实际是否支持粤语识别，取决于用户手机的语音服务。
- **文本识别准确 ≠ 粤语发音、韵母和声调准确**。目前是基础阶段，不提供真正的音频音素/六声调自动评分，不假称已接入可量化的 AI 纠音模型。
- 本地字幕解析、词条和预置句不需要账号或付费 API；系统识别服务是否在线由设备所装服务决定，无法承诺离线识别。

粤拼方案出处：
- [香港语言学学会 Jyutping 官方方案](https://lshk.org/jyutping-scheme/)
- [粤拼介绍与标准拼写](https://jyutping.org/jyutping/)

粤语功能代码：\`JourneyCantonese.java\`；单元测试：\`JourneyCantoneseTest.java\`；在现有原生 \`JourneyImmersionActivity\` 里直接使用，不安装浏览器插件。

## 已知限制

- **未集成 Undertone 官方插件**：它是面向浏览器视频站点的扩展，不是可直接移植的安卓接口。
- 不支持抓取或破解 Netflix、YouTube 等站点的受版权/DRM 保护内容。仅使用用户合法获取的本地视频/字幕。
- 无自动从视频转写字幕、机器翻译、日语假名注音或上下文 AI 解释以及粤语音素/声调评分；这些是后续独立功能，不能当作已完成。
- 本轮新模块需要通过安卓设备测试，尤其是 seek、pause、音频路由、视频兼容性与生命周期。
- 当前仓库仍依赖已经备份的完整旧版 APK 快照来重打包历史功能；**仅有公开源码不代表可以生成完整最新版 APK**。已有 `scripts/build-5.0.0-snapshot.sh` 可作为后续打包基础，但原签名私钥应留在私有备份，不能复制到公开仓库。

## 文件

- `JourneyImmersionActivity.java`：本地播放与交互 UI
- `JourneySubtitles.java`：字幕解析与定位
- `JourneySubtitlesTest.java`：无 Android 依赖的解析测试
- `JourneyActivity.java`：入口
- `AndroidManifest.xml`：非导出 Activity 注册

## 接入后的手工测试

1. 在 Android 13 及以上系统中使用文件选择器打开合法的本地 MP4。
2. 分别导入 SRT 日文和中文字幕，检查时间轴、断句与间隔无字幕的表现。
3. 暂停、拖动进度条、点句跳转、循环和切后台后返回。
4. 收藏三条句子，导出 TSV，在 Anki 中尝试以 Tab 分隔导入。
5. 返回 Everyone 原有英语课程、AI 对话与纠音入口，确认数据未被覆盖。
