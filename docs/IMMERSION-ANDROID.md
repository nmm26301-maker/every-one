# Everyone · 多语言原生影视精听（粤语 / 日语 / 英语）

本分支新增 **Android 原生影视精听**，入口位于 Everyone 5.0 首页的“影视精听 · 双语字幕 / 逐句复读”。当前核心功能不依赖浏览器扩展，和下列外部项目没有商业、技术或授权关联。

## 已实现的能力（源码）

- 安卓系统文件选择器导入本地视频（播放器使用系统 `VideoView`，格式依手机解码器而定）。
- 分别加载日文或英文 **SRT/WebVTT** 原文字幕，以及中文字幕；按时间轴而非相同序号配对。
- 视频时间轴自动定位台词，点字幕列表跳转、上一句、下一句、重播。
- 可选句末暂停或单句循环（短句及播放器 seek 精度因手机而异）。
- 选择台词后保存到本地收藏（原文/译文），导出 Anki 可导入的 TSV。
- 少量**规则式**日语口语缩略提示：`ちゃった`、`じゃん`、`っす`、`ちょっと`、`考えておきます`。
- 播放与字幕无需网络，未集成付费 API，不上传用户视频。


## 已明确的分语言参考项目（2026-10-21 用户更正）

**粤语（广东话）采用两套互补参考，而不是 Undertone：**

1. [DualSub Replay](https://github.com/hoangkien1703/dual-sub-replay)：开源 Android 应用，侧重带字幕的 YouTube 视频、双语字幕、点句重播、查词/收藏。它是通用语言学习工具，**不是专门的粤语语音识别模型**；某个粤语视频的原字幕是否存在取决于 YouTube 资源。上游项目 MIT 许可。Everyone 目前仅有本地视频+SRT/VTT，不宣称已经接入它的 YouTube 播放能力。
2. [Cantonese Learner V2](https://github.com/lyhjeremy/cantonese-learner-v2) / [可直接试用的网页](https://lyhjeremy.github.io/cantonese-learner-v2/)：专门的香港粤语学习项目，提供港式口语对话、新闻书面语/口语并排、按字粤拼、示范发音、跟读及文字识别式反馈。可在安卓浏览器打开，部分朗读/识别依赖浏览器与设备环境。它展示的字符识别评分不等于自动评估声母韵母及全部六调。上游仓库 MIT 许可；内容来源、音频和第三方服务须另核实授权，不自动纳入 Everyone。
   
**日语采用单独参考：**

3. [Undertone 弦外](https://undertone.day/) / [Chrome 插件商店](https://chromewebstore.google.com/detail/baeckicjpfmgblnpnkdpfgbejobaeebe)：明确**目前主要支持日语**，主打 Netflix/YouTube 日语字幕的假名注音、口语缩约、礼貌程度/语气/言外之意及逐句复读。官方声明需**电脑 Chrome**，不是 Android 原生插件。Everyone 内部的少量规则式日语解析不是 Undertone 本身，亦未获得其闭源功能实现。

**产品目标分工**：粤语优先学习「YouTube 视频双字幕/逐句回放 + 港式对话/粤拼/跟读」，日语优先学习「日语影视口语注音/缩约/语气/言外之意」，英语继续保留既有课程及精听。这是后续独立开发时的对标清单，不意味着上述软件已直接集成或已有合作授权。

## 粤语 · Jyutping + 影视台词学习（2026-10-21）

在原来的英语、日语影视精听功能之外，同一个页面加入 **粤语**：

- 首页语言切换：粤语 / 日语 / 英语，保留上一次选项；默认粤语。
- 粤语电影/电视剧原声视频可以配合用户导入的粤语 SRT / WebVTT 和中文字幕做逐句学习。
- 内置 10 句繁体粤语入门练习，显示香港语言学学会粤拼（Jyutping，六调数字 1–6）、普通话意思与基础发音提示。
- 点击粤语字幕中的「显示口语说明」，可从内置常见词条列表逐项查看词义和粤拼。覆盖唔、冇、喺、係、咗、緊、啲、嘅、咩等常见影视词。
- 「跟读识别 · 对照文本」会调用手机现有的系统语音识别，粤语使用请求语言 \`zh-HK\`，日语 \`ja-JP\`，英语 \`en-US\`。可对比识别到的文字和字幕原文，方便自主回听原声；系统实际是否支持粤语识别，取决于用户手机的语音服务。
- **文本识别准确 ≠ 粤语发音、韵母和声调准确**。目前是基础阶段，不提供真正的音频音素/六声调自动评分，不假称已接入可量化的 AI 纠音模型。
- 本地字幕解析、词条和预置句不需要账号或付费 API；系统识别服务是否在线由设备所装服务决定，无法承诺离线识别。

粤拼方案出处：
- [香港语言学学会 Jyutping 官方方案](https://lshk.org/jyutping-scheme/)
- [粤拼介绍与标准拼写](https://jyutping.org/jyutping/)

## v5.0.2 安卓独立预览（2026-10-21）

这次增加**手机直接录制自己的跟读、即时回放以及字幕同步校准**。用户选择本地合法视频及 SRT/VTT 后，可反复听当前句，再点击「● 录我的声音 / 停止」录一遍，点击「▶ 回放我的录音」听自己与原声的差异。默认最多录 30 秒，在切后台时停止录制，销毁页面会删除临时音频。Android 首次使用会询问麦克风权限；拒绝后依然能看视频与字幕。

字幕校准按钮「字幕提前 0.5s / 同步重置 / 字幕延后 0.5s」在 ±10 秒之间调节。字幕整体偏移同步用于原文、译文、逐句跳转与单句循环；偏移量在设备上保存，方便继续使用。偏移量为正代表字幕延后，字幕不会被提前显示在片头。

**独立预览包**：`org.openenglish.reader.preview`、`versionName=5.0.2-preview`、`versionCode=2`。GitHub Actions 会产生已签名预览 APK，供安卓手机自测，但**不与原始 Everyone 5.0.0 使用相同包名或签名**，不会覆盖原版的聊天与课程。预览 APK 使用 GitHub Actions 每次临时创建的签名密钥，因此新预览版通常不能直接覆盖旧预览版；安装提示签名不一致时只卸载旧**预览版**，不能卸载原始 Everyone。独立预览的收藏数据因此不承诺保留，需提前导出 Anki TSV。

系统语音识别会根据机器上的语音服务决定是否联网；本地录音回放及字幕解析不联网。**系统文字匹配不是声母、韵母或六声调的客观纠音评分**，真实的手机声学和不同 ROM 兼容性仍待实测。

## v5.0.4 完整覆盖包 / v5.0.5 独立测试包（2026-10-21）

**本次修正了“凭一个录音走势就断言六调准确”的误导风险：**

- 新增可视化 F0 曲线，纵轴为相对音高（半音），横轴为录音时间。音量小或无清晰基频的时间段保留空白，不会人为连线。
- 仅接受录制的 **0.25–3 秒单音节**。有效有声帧不足或检测到两个明显分开的有声段，会返回具体重录原因；3 秒以上在音频解码阶段就被拒绝，减少耗时和内存。
- 曲线可以帮助练习**上扬、下降或大致平稳**。但平调 1/3/6 的绝对音高位置无法仅靠走势区分，也不能判断声母、韵母或说话者本身的调域，**不要将本功能当作客观六声调准确率评分**。
- 基频算法仍为软件近似法，合成音频回归测试覆盖上扬/下降/平稳、静音、过短、过长及分离双音节，**未完成真实粤语语料标注验证、真实安卓多机型录音测试**。
- 原签名正式版 \`org.openenglish.reader\`、\`versionName 5.0.4\`、\`versionCode 63\`；独立预览版 \`org.openenglish.reader.preview\`、\`versionName 5.0.5-preview\`、\`versionCode 5\`。独立预览每次使用临时签名，升级可能需卸载旧预览；原 Everyone 主 App 不得提前卸载。

## v5.0.7 原签名完整版 / v5.0.8 独立预览：真实参考音对照（2026-10-21）

在原有粤语十句教材、字幕逐句复读、粤拼拆解、六组最小对立音、系统 TTS、本人回放、单次 F0 分析和可选 SenseVoice 转写之外，增加了**参考音和学习者录音的音高走势比较**。

- 导入你合法获取的**真实粤语真人单音节 AAC/M4A**，或先录一段并保存为临时参考音。每次小于 2 MiB，经本机音频解码后要求约 0.25–3 秒、单个清晰有声音节；参考/跟读两段分别进行有效性判断。
- 两段曲线各自按中位 F0 归一化，再在统一的音节相对时间轴上插值 24 点。绿色是参考，紫色是本人；文字反馈包含两段上扬/下降/平稳走势、曲线均方根差异（相对半音），不把这些数字当成发音准确度得分。
- **绝对音高被归一化**：不同说话人声区不同的情况可以比较升降形状，但无法评估粤语高平调 1、中平调 3、低平调 6 的相对音区，也不判断声母/韵母。图表对不上可能是读了不同音节、参考音质量不足或检测错误，不能简单归咎于发音者。
- 导入、保存参考和对比均由用户点击触发，音频仅在 App 私有临时缓存中，不上传；页面销毁后删除参考与练习音。此功能无网络需求，和可选的远程 SenseVoice 服务是两套独立流程。
- 新 Java 回归测试覆盖不同音高声线下相同上扬轨迹、相反下降轨迹、静音/过长参考音拒绝及不显示虚假百分制。CI 用 Android 35 完整编译并制作独立签名 APK。**测试使用合成正弦波，不是经过真实粤语发音者验证的声学评估。**

## 5.0.10 完整版 / 5.0.11 预览：快捷跟读稳定性优化（2026-10-21）

这版不新增云端模型，主要修复上一版「打开立即跟读」的状态混乱：

- 快捷卡片的录音按钮有明确的 `● 开始录音` / `■ 停止录音` 状态；手动停止后立即显示「点回放」，录音过程不允许边录边回放，避免误触。
