# Everyone 5.0：从零基础走向独立交流

这一版把课程、纠音、对话和复习接成一个完整训练流程。它提供训练工具和核心路线，不承诺学习固定天数后能在所有话题、语速、口音中无障碍交流，也不把课程完成度当作 CEFR 认证。

## 安装与第一次使用

沿用原应用包名与签名，覆盖安装，避免先卸载。首页为新的学习路线；原有阅读、听写、素材、多语言和对话仍可从“原有工作室”进入，原有数据库不迁移、不清空。

1. 零基础从第一阶段开始。已有基础可以用“选择起点 / 自测任务”选择练习阶段，随时调整。
2. 每天先练到期复习，再学一个单元。48 个单元、144 条双语表达覆盖六个阶段，每课含句型解释、发音重点和脱稿场景任务。
3. 每句先听英语选中文意思，再看解释、听示范、录音、回听、调整。录音最长 12 秒，适合单句；长表达在场景对话中分轮练习。
4. 隐藏英文，用中文意思提示自己说出来，再诚实选择“能说出 / 还说不出”。系统按 10 分钟、1、3、7、14、30 天安排复习，提前重复不会跳级。
5. 进入场景对话，使用自己的信息，至少回应三轮、追问一次、遇到不懂主动澄清。可请求中文提示和对话复盘。

## 纠音如何工作

| 模式 | 能做什么 | 条件与限制 |
|---|---|---|
| 真实音素评测 | 发送真实录音，显示 Azure 返回的句子/单词/音素评分、漏读多读及针对性发音动作建议 | 在设置输入自己的 Azure Speech 区域和密钥并选择此模式。会向该服务上传这段录音，服务可能收费。当前为美式英语参考，噪声和口音可能影响结果 |
| 识别对照 | 用本地 Whisper 或配置的转写接口识别，再标出漏词、额外词和替换词 | 识别结果可能有误；文字一致不代表音素发对。没有音素分数 |
| 录音回听 | 听示范、录音、回听并按发音要点自查 | 无自动评分，不需要云端评测密钥 |

音素反馈只显示服务实际返回的字段。缺失分数不填 0；整体准确度不会被伪装成音素分数；文本相似度不会转换成“发音分”。音素标签沿用服务的 IPA/SAPI 表示，常见标签映射到中文口形与气流指导。75 是安排练习的提示线，不是能力证书。没有足够评分时明确提示重录。优先练最多三项，避免一次处理过多问题。

步骤：听示范 → 单词慢读三次 → 放回整句 → 重录 → 回听。目标是清晰可懂；不要求消除合理的地域口音。

## 对话与模型

默认使用已有本地模型设置。本地语音识别需要英语 Whisper 模型，对话需要 DeepSeek 1.5B；可从“安装 / 导入 / 管理本地模型”检查。现有本地引擎需要 64 位 ARM 手机，首次加载可能较慢。

也可配置兼容 OpenAI 格式的 HTTPS 对话/转写接口，并关闭本地模式。语音输入先变成可编辑文字，确认后再发送；失败时保留已保存的对话并给出重试入口。AI 可能出错，小型本地模型对复杂任务的表现有限。连续语音按钮进入原有稳定语音模式；新的分级对话在当前页面进行。

场景提示按学习阶段调整句长、词汇和任务，要求回应含义、只修正一个重要表达问题、继续追问。AI 不从文字判定发音或授予英语等级。中文提示和复盘仅根据现有对话。

## 数据与隐私

学习路线数据独立保存在 `journey_progress_v1`，不改变原有工作室数据库。最近对话每场景保留 30 条，避免无限膨胀。可导出和导入 JSON 学习备份，包含课程进度、复习、反馈和对话；不包含密钥或录音。导入先验证结构、课程标识和范围，确认后才替换。

录音只用于当前页面回听，离开页面/切到后台时删除；录音与请求在离开页面时取消，过期回调不能写入其他课程。服务密钥沿用 Android KeyVault 加密存储。开启 Azure 评测只授权该模式的短录音上传；本地/云端对话模式单独配置。

原有工作室数据请继续使用其备份入口。新路线与旧工作室备份范围不同，设置页面明确说明。

## 能力检验与下一步训练

六阶段覆盖：声音与常用回应 → 个人信息与简单交易 → 生活事务 → 叙述与理由 → 权衡、协商和深入讨论 → 话轮、隐含意思、语域与沟通修复。每阶段提供可观察的交流任务；不要仅背 144 句或刷分。

持续导入真实音视频，练不同语速和口音；把听过的内容复述，再与交流对象讨论。真实交流反馈、跨话题迁移、反应速度和澄清能力比课程打卡更能反映是否能沟通。应用提供 AI 训练，不提供真人匹配。

## 验证范围

本版新增模块可独立编译；测试覆盖复习时序、提前练习防跳级、识别与发音评分区分、缺失评分、真实低音素反馈解析、备份恢复和最近对话范围。打包时校验原 4.7.2 编译类和模型/资源字节保持不变，新增模块调用的旧方法必须存在。

构建入口是 `scripts/build-5.0.0-snapshot.sh`，不是旧的 `build.sh`。中间版本部分 Java 源码尚未恢复；既有功能通过固定 SHA-256 的 4.7.2 编译快照保留。新增课程、学习界面及其规则的完整源码均在本仓库，恢复包保存新资源以支持逐字节重建最终签名 APK。

模拟器仅验证界面流程；测试用 APK 排除 ARM 本地库以运行在 x86_64，用户安装包保留全部原库。模拟器检查不等于真机麦克风、本地模型性能、真实云端评分质量或真人交流效果测试。没有用户评测密钥的情况下，不宣称完成 Azure 在线评分实测。

设计依据：[Council of Europe CEFR descriptors](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors)、[Microsoft Speech pronunciation assessment](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)。阶段为教学组织参考，不是官方考试。
