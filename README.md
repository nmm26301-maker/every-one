# Everyone 4.5 · 纠音魔法镜

这版优先完善课内纠音练习：完整跟读后，自动按课程的预期音素定位音节 / 日语拍子，逐段听示范与自己的声音，再只练一段。保留魔幻小精灵界面和全部原有英语、三语对话、长期记忆、复习与备份功能。

## 手机使用

1. 用 `Everyone-AI-English-4.5.apk` 覆盖安装，勿先卸载。包名和签名沿用 4.4；覆盖安装路径已核对，但此次没有手机升级实测。
2. 进入语言魔法岛 → 粤语 / 日语 / 普通话 → 选一关。先听示范，点底部录音，再点一下结束。最长 12 秒。
3. 完整录音保存后，纠音魔法镜会自动分析；首次在本机解包约 153 MiB 的内置模型。无需下载、账号或 API Key，可随时取消。
4. 选一个片段，用“示范 / 我”听差异，再点“只练…”；底部录音按钮变成对应片段。录下一遍后，会显示这段的时长辅助和练习动作。单段录音不覆盖完整跟读，不重复奖励星光。
5. 点“回到完整跟读”退出单段模式。可以重新分析完整录音，也可核对完整句子的 Whisper 字样。Whisper 字样不会当作发音准确率。

逐段模型需要 ARM64 Android 7.0+；原应用 Android 6.0 的听示范 / 跟读 / 旧纠音辅助保留。全双工、聊天模型设置和长期记忆沿用之前版本。纠音分析与 Whisper 核对互斥，避免同时加载两个分析任务。分析和模型解包均在工作线程；取消会中断正在运行的 ONNX 推理。离开页面丢弃旧结果。

## 这次具体在练什么

- 粤语 / 普通话：逐音节回放、相对音高走势与节奏提示；相应声调动作；n/l、平翘舌、送气和入声的口型 / 舌位练习动作。
- 日语：逐拍对照；两拍长音合并回放，连续元音不人为插入停顿；促音单独保留练习片段。节奏用片段在整句中所占时长作辅助，避免把整体读得慢直接当作错误。
- 单段专练：听这段示范 → 听自己 → 改一个动作 → 再放回整句。原始完整录音仍可回放、核对字样和备份。
- 取消 / 超时 / 片段切分失败：完整录音保留，不扣星光。某音素在示范或跟读中未切出时，不提供该段的专练 / 切片回放；请完整对照听。
- 口型、舌位、拍子关不再显示音高走势分；其他关的界面也不再展示 `/100`，避免把曲线相似度误当发音准确率。

## 能力界限

TIFA 1.0 ST 是音素时间对齐模型：输入课程的预期发音，输出片段位置。对齐不证明读对字，更不证明音素正确。切分也可能出错。当前用它辅助逐段回放与声调 / 节奏练习，**没有经过校准的声母、韵母、日语元音自动判错或发音准确率**。

候选听辨在普通话 n/l 部分示范上不稳定，因此未作为自动纠音结论。平翘舌候选测试仅用于研究，未发布为诊断。真实学习者的声母韵母误读仍需要可靠评测模型和母语教师验证；AI 对话的文字回复也不能替代听音评测。

仍是 204 个固定课程模板，不能对任意聊天内容做逐音素评测。合成示范尚未逐条经过母语老师审核。使用安静环境，自然读，不耳语、不喊。暂无小米 10 Pro / Android 实机麦克风、TTS 回调、升级、帧率或延迟测试；不能承诺零延迟。

## 构建与验证

`ANDROID_HOME=/path/to/sdk bash build.sh` 使用预编译模型和 native 库构建 APK，不联网。

`JSON_JAR=/path/json.jar ORT_HOST_JAR=/path/onnxruntime-1.22.0.jar bash tests/test-tifa.sh`：200 组与上游解码器对照的 fixtures、全部 204 关真实 Java 模型推理、逐段回放范围、日语长音合并、取消与恢复、练习动作等 1784 项检查通过。Java 与 Python 参考切分最大偏差为 0 帧。这是对齐实现验证，不是学习者发音准确率验证。

此前 670 项回归检查通过；当前没有 Android 手机 / 模拟器执行环境。日志见 `qa/v45-*` 和 `VALIDATION.md`。

可选重新导出模型：按 `vendor/tifa/README.md` 获取并校验原模型后，执行 `python3 scripts/build-tifa-assets.py --weights-dir /path/TIFA-1.0-ST`。源码包包含固定上游代码、两份已导出的 ONNX、许可、课程、测试、旧 native 源码 / 预编译库与原签名密钥，正常构建无需重复导出。
